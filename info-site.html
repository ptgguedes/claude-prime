Fonctionnement

Le site est composé de pages HTML statiques, sans base de données ni compte utilisateur. Les pages chargent leur feuille de style et leurs scripts depuis le site lui-même, sans police, script ni image venant d'un autre domaine.

Le seul échange avec un autre serveur a lieu lorsque vous envoyez un message depuis la page Contact.
