Ce que contient le site

La page Outils de vibe coding compare deux listes : un post publié sur X et la liste « awesome-vibecoding » de GitHub. Elle contient un tableau pour chaque liste.

Se repérer

  • Le menu « Sur cette page », en haut de la page, mène aux quatre parties : comparaison, source A, source B, sources.
  • Le pied de page, identique sur toutes les pages, donne accès à ce contact, à cette aide et aux informations légales.

Filtrer les tableaux

  • Le champ « Filtrer les deux tableaux » garde seulement les lignes qui contiennent le texte saisi.
  • Les boutons de catégorie (prompts, inspiration, design system, composants UI, animation) filtrent le tableau de la source A.
  • Le filtrage a besoin de JavaScript. Sans JavaScript, les tableaux ne s'affichent pas.

Lire le tableau de la source B

  • « Access / scope » indique comment accéder à l'outil et ce que l'accès couvre. « Check pricing » veut dire que le prix n'a pas été examiné en détail dans la liste d'origine.
  • « Vérifié » donne la date de vérification dans la liste d'origine. Ce n'est pas la date de sortie de l'outil.

Affichage et clavier

  • Le thème clair ou sombre suit le réglage de votre appareil.
  • Vous pouvez agrandir le texte avec le zoom de votre navigateur.
  • Toutes les actions se font au clavier : touche Tab pour avancer, Entrée pour activer un lien ou un bouton.
